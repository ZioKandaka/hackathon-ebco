# Data Model: Location Discovery AI Skill

## 1. Entities & Data Structures

### Discovery Spot Candidate (`DiscoverySpot`)

Represents a ranked candidate location point generated by the discovery engine.

| Field Name | Type | Description |
|------------|------|-------------|
| `rank` | Number | Rank position (1 to 5) |
| `name` | String | Spot designation (e.g. "Candidate Spot #1 - Kediri Center") |
| `latitude` | Number | Latitude coordinate |
| `longitude` | Number | Longitude coordinate |
| `demandScore` | Number | Composite demand density score (0 - 100) |
| `competitionCount` | Number | Count of direct competitor POIs within search radius |
| `rationale` | String | Natural-language explanation of why spot scored well |
| `regencyCode` | String | Target regency/city code |

## 2. BigQuery POI Schema Mapping (`bni-geospatial-845e.bni_geospatial_gold_zone.obt_poi_gold`)

Query input attributes for BigQuery POI dataset queries matching Constitution Section IV:

| Column Name | Type | Description |
|-------------|------|-------------|
| `poi_id` | STRING | Unique POI identifier |
| `poi_name` | STRING | Name of point of interest |
| `poi_type` | STRING | Business category / POI type |
| `latitude` | FLOAT | Latitude coordinate |
| `longitude` | FLOAT | Longitude coordinate |
| `province_code` | STRING | Partition column |
| `regency_code` | STRING | Partition/clustering column |
| `province` | STRING | Province name |
| `regency` | STRING | Regency or city name |

## 3. Workflow Sequence

```
[ User Request in Chat ]
          │
          ▼
[ Extract Business Type & Target Region ]
          │
          ├── (Missing Region or Type) ──► Prompt User for Clarification in Chat
          │
          └── (Valid Parameters) ──► Query BigQuery POIs with Regency Filter
                                                │
                                                ▼
                                    [ Compute Demand vs Competition Score ]
                                                │
                                                ▼
                                    [ Rank Top 5 Candidates + Generate Rationale ]
                                                │
                                                ▼
                                    [ Stream Results via SSE & Render Map Pins ]
```
